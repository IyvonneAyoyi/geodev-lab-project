## Data Preparation

All the datasets arrived in EPSG 4326 (Nairobi County, DEM, Settlements, Rivers and Streams).

All layers were projected to EPSG:32737 (WGS 84 / UTM zone 37S) since the project involves spatial measurements such as distance between settlements and waterways. EPSG:32737 is a projected coordinate system using metres, making it appropriate for spatial analysis within the Nairobi study area.
