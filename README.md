# Nairobi Flood Exposure

A geospatial project investigating potential flood exposure of settlements in Nairobi County.

## Research Question

**Which settlements in Nairobi County sit in low-lying areas near rivers?**

## Data Sources

* **GRID3** — Settlement extents
* **SRTM / Copernicus DEM** — Elevation data
* **OpenStreetMap (OSM)** — Rivers and waterways
* **Administrative boundary data** — Nairobi County boundary
